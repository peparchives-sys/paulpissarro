AbstractPropositionsLedger
Pre-deposit. The ledger is published before the first deposit, empty and dated, rather than after.

Ledger not yet opened. The opening date is permanent once set, and must be set before the first deposit.

A public record of every citation this work receives. It is opened and dated before the first deposit, because an empty ledger published in advance demonstrates that the wager was made before the outcome was known, and one produced afterwards demonstrates nothing. An accruing record supports the claim; an empty one would be equally visible. That is the point of publishing it.

Entries

None yet. Nothing has been deposited, so nothing can have cited it.

Cadence

Sources are checked monthly by hand until volume justifies automation, so a gap reads as schedule rather than concealment. Citations that fall outside the indexes, in catalogues, syllabi and reviews, are recorded here too: those are the ones the machines miss.

Sources polled

  • CrossrefRegistered links between DOIs. The machine-countable spine.
  • OpenAlexOpen bibliographic graph with a public API.
  • Semantic ScholarA second open graph, used as a cross-check.
  • Google ScholarNo API. Checked manually, and the broadest capture: books, theses and grey literature.
  • ManualCatalogues, syllabi, reviews, exhibition texts.

Schema

Each entry is one object in ledger.json, keyed on the citing DOI so the same citation found in several sources is recorded once.

{
  "edge":          "cited-by",
  "citing_author": "",
  "citing_title":  "",
  "venue":         "",
  "year":          0,
  "citing_doi":    "",
  "cites_prop":    "",   // which proposition, if identifiable
  "cites_node":    "",   // which bibliography node, if identifiable
  "date_added":    "",
  "source":        ""    // crossref | openalex | semanticscholar | scholar | manual
}
